val clientAuthKid: String?

The id of the client key this session or sign-in is bound to, if one has been recorded. A relay must sign with exactly this key or refuse: the server deletes a session presented with another key.

val outcomeInDoubt: Boolean

true when an earlier attempt with this same refresh token ended without a definitive answer. The token may already be spent, so the request must not be sent by any route that cannot recover the earlier response. Only ever true for TokenEndpointRequestKind.Refresh and only when TokenEndpointTransport.tracksRefreshOutcome is set.

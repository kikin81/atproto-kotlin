# Overlay Retirement Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Retire the ten vendored lexicon overlays the AT Protocol network has now adopted, keep the one that is still load-bearing, and close the detector blind spot that hid six of them — with a byte-identical `models/api/models.api` as mechanical proof that no public API changed.

**Architecture:** Two independent changes in one PR. First the detector (`:generator`) gains two signals: a *redundancy* verdict computed from a document the staleness workflow already downloads and throws away, and an `expectDrift` manifest flag that silences a deliberate superset overlay without muting it permanently. Then the retirement itself: delete ten overlay files and manifest entries, add five NSIDs to `generator/lexicons.json`, and gate the whole thing on `git diff --exit-code models/api/models.api`.

**Tech Stack:** Kotlin/JVM (`:generator`, JUnit 5 via `kotlin.test`), kotlinx.serialization, KotlinPoet, `@atproto/lex` npm CLI, GitHub Actions + `jq`, Gradle 9.3.1, kotlinx binary-compatibility-validator.

**Spec:** `docs/superpowers/specs/2026-07-25-overlay-retirement-design.md`

## Global Constraints

- **JDK 17** (tracked by `.java-version`); **Node 22+** for `npx lex install`.
- All work happens on branch `chore/retire-stale-overlays`, already rebased onto `origin/main` (`3e81a755`).
- **Conventional Commits**, enforced by commitlint via a `commit-msg` hook. Every commit in this plan is `chore(...)` — `:generator` is unpublished and `models.api` must not change, so nothing here warrants a version bump from semantic-release.
- **Spotless + ktlint 1.4.1** run as a pre-commit hook. No wildcard imports. Run `./gradlew spotlessApply` before committing Kotlin.
- **Never hand-edit `generator/lexicons.json` `resolutions`.** It is a lockfile; `lex install --ci` errors when installed lexicons don't match its pinned CIDs. See Task 5, Step 9.
- **Do not run the full `./gradlew build`.** iOS simulator test-linking fails on a Command Line Tools-only machine. Use the targeted commands each task specifies.
- The spec describes two commits; this plan produces six, in the same order and grouping (detector first, retirement second). Finer commits keep each test cycle reviewable. All are `chore`, so release behaviour is unchanged.

```kotlin
/** Per-overlay result fed to the report renderer. */
internal data class OverlayStatus(
    val nsid: String,
    val publishable: Boolean,
    val drift: DriftStatus,
    // Honors the manifest opt-out: an overlay pinned with removeWhenPublished=false
    // is intentionally kept even after upstream publishes, so it must NOT be flagged
    // for retirement. Defaults true (the common case).
    val removeWhenPublished: Boolean = true,
    // The vendored copy is byte-identical to the document `lex install` fetches, so
    // the overlay contributes nothing and is safe to delete. Deliberately IGNORES
    // removeWhenPublished: a pinned shadow whose local additions upstream has since
    // absorbed is exactly the case the drift-only comparison could never see.
    val redundant: Boolean = false,
) {
    /**
     * Stale = actionable: redundant (delete it), retire (publishable AND opted in to
     * removal), or re-vendor (drifted/removed). A pinned overlay
     * (removeWhenPublished=false) still surfaces drift — we just never tell the
     * maintainer to retire it.
     */
    val isStale: Boolean get() =
        redundant || (publishable && removeWhenPublished) || drift != DriftStatus.InSync
}
```

In `.github/workflows/overlay-staleness.yaml`, replace the body of the `Probe overlay publishability` step's `run:` (keeping the existing comment block above it intact) with:

```bash
          set -euo pipefail
          map='{}'
          redundant_map='{}'
          for nsid in $(jq -r '.overlays[].nsid' overlay-lexicons.json); do
            tmp_manifest="$(mktemp)"
            tmp_dir="$(mktemp -d)"
            # Seed a valid EMPTY manifest. @atproto/lex parses --manifest BEFORE
            # any network resolution, so a zero-byte file (bare mktemp) — or one
            # missing the required `resolutions` key — fails with "Unexpected end
            # of JSON input" and the probe would ALWAYS fall to publishable=false,
            # making the retire signal unreachable even after Bluesky publishes the
            # record. An empty-but-valid manifest lets the resolver actually run, so
            # exit 0 genuinely means "now resolvable on-network".
            printf '%s' '{"version":1,"lexicons":[],"resolutions":{}}' > "$tmp_manifest"
            if npx lex install "$nsid" \
                 --manifest "$tmp_manifest" \
                 --lexicons "$tmp_dir" >/dev/null 2>&1; then
              publishable=true
            else
              publishable=false
            fi
            # Redundancy: the resolver just wrote the real on-network document into
            # $tmp_dir. Compare it to the vendored copy instead of discarding it —
            # this is the only signal that catches a pinned shadow whose local
            # additions upstream has already absorbed. `del(.["$type"])` strips the
            # com.atproto.lexicon.schema wrapper key that lex install adds and the
            # vendored copies lack; -S sorts keys so re-ordering isn't a difference.
            path="${nsid//./\/}"
            fetched="$tmp_dir/$path.json"
            vendored="overlay-lexicons/$path.json"
            redundant=false
            if [ "$publishable" = true ] && [ -f "$fetched" ] && [ -f "$vendored" ] &&
               diff -q <(jq -S 'del(.["$type"])' "$fetched") \
                       <(jq -S . "$vendored") >/dev/null 2>&1; then
              redundant=true
            fi
            echo "probe: $nsid -> publishable=$publishable redundant=$redundant"
            map="$(jq --arg n "$nsid" --argjson v "$publishable" \
              '. + {($n): $v}' <<<"$map")"
            redundant_map="$(jq --arg n "$nsid" --argjson v "$redundant" \
              '. + {($n): $v}' <<<"$redundant_map")"
          done
          {
            echo "OVERLAY_PUBLISHABLE_JSON<<EOF_overlay_publishable"
            echo "$map"
            echo "EOF_overlay_publishable"
            echo "OVERLAY_REDUNDANT_JSON<<EOF_overlay_redundant"
            echo "$redundant_map"
            echo "EOF_overlay_redundant"
          } >> "$GITHUB_ENV"
```

Note `diff <(...)` is a bash process substitution — GitHub Actions `run:` uses bash by default, and the step must keep `working-directory: generator` so `overlay-lexicons/...` resolves.

```bash
     diff -q <(jq -S 'del(.["$type"])' "$fetched") <(jq -S . "$vendored") >/dev/null 2>&1; then
    redundant=true; fi
  echo "probe: $nsid -> publishable=$publishable redundant=$redundant"
  map="$(jq --arg n "$nsid" --argjson v "$publishable" '. + {($n): $v}' <<<"$map")"
  redundant_map="$(jq --arg n "$nsid" --argjson v "$redundant" '. + {($n): $v}' <<<"$redundant_map")"
done
export OVERLAY_PUBLISHABLE_JSON="$map" OVERLAY_REDUNDANT_JSON="$redundant_map"
cd -
```
